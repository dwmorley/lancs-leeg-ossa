# Shiny Python App

This is a simple Shiny app built with Python using Poetry for dependency management.

## Setup

1. Ensure Poetry is installed.
2. Run `poetry install` to install dependencies.
3. Run `poetry run shiny run app.py` to start the app.

## Linting

- Use `poetry run flake8` for linting.
- Use `poetry run black app.py` to format the code.

## Pre-commit

- Run on all files: `poetry run pre-commit run --all-files`
